Chord Lab v5 — Studio UI

변경: UI를 차콜/라임으로 재정리, 코드표 메뉴로 이름 변경, 아이콘을 기타 픽토그램으로 교체, 운지표 점 크기 축소.
환경설정: 우측 상단 설정 → 음량 / 앱 화면 밝기 / 강조 색상 선택. 설정은 브라우저에 저장됩니다.

HTML 단독 실행: ChordLab_Studio_v5.html을 브라우저에서 엽니다.
모바일 앱(PWA) 설치: 이 ZIP 내용 전체를 HTTPS 정적 웹 호스팅에 올린 뒤 브라우저에서 홈 화면 추가/설치를 선택하세요. ZIP을 휴대폰에서 직접 열어도 자동 설치되지는 않습니다.
기존 코드 진행은 저장소 키가 같고 같은 사이트의 동일 도메인에 배포할 때 유지됩니다. 업데이트 전에 JSON 백업을 권장합니다.
앱 밝기는 기기의 시스템 밝기를 변경하지 않습니다.
